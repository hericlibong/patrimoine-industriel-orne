# Qualification des droits et usages des médias V1

Date : 2026-07-29

## Décision d'usage

| Niveau | Règle appliquée |
|---|---|
| Consultation interne | Métadonnées, liens et crédits seulement pour les 1 900 médias. |
| Prototype privé | Aperçu distant crédité seulement pour les médias avec crédit source ; aucune copie locale. |
| Publication publique | Aucune image autorisée par défaut ; autorisation ou licence documentée requise. |

## Résultats

- médias avec droits explicitement protégés : **1783** ;
- médias aux droits inconnus : **117** ;
- médias nécessitant une autorisation avant publication : **1900** ;
- médias publiables automatiquement : **0** ;
- crédits sources à conserver : **1783** ;
- crédits à compléter : **117** ;
- lignes du registre de demandes : **1888**.

## Sources et limites

- POP distingue les données descriptives des images, qui peuvent être soumises aux droits de tiers ;
- le registre prépare les demandes mais n'envoie aucun message ;
- aucun média n'est téléchargé ni versionné ;
- cette qualification organise le travail éditorial et ne remplace pas une analyse juridique d'un cas particulier.

Références : https://pop.culture.gouv.fr/conditions-generales-utilisation ; https://pop.culture.gouv.fr/donnees-ouvertes.
